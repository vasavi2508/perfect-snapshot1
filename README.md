# 📸 Capture Moments – Photography Portfolio Website

**Capture Moments** is a modern and elegant photography portfolio website designed to showcase professional photography services, creative work, and photography packages.

The website highlights beautiful moments through photography and allows visitors to explore the photographer's portfolio, learn about available services, view packages, and send enquiries for booking photography sessions.

## 🌟 Features

- **Home Section:** Attractive hero section with a photography background and navigation.
- **About Section:** Introduction to the photographer, experience, and achievements.
- **Gallery Section:** Beautiful photography collection featuring wedding, portrait, nature, fashion, travel, and event photography.
- **Services Section:** Six photography services with detailed descriptions.
- **Packages Section:** Three photography packages with pricing and features.
- **Testimonials:** Customer feedback and photography experiences.
- **Contact Section:** Contact form for photography enquiries and bookings.
- **Social Media:** Instagram and Facebook links.
- **Responsive Design:** User-friendly navigation for desktop and mobile devices.

## 📷 Photography Services

The website offers the following services:

1. Wedding Photography
2. Portrait Photography
3. Event Photography
4. Fashion Photography
5. Product Photography
6. Nature Photography

## 💎 Photography Packages

The website presents three photography packages with different features and pricing options, allowing customers to select a suitable photography session.

## 🚀 Getting Started

To run the project locally, you need the complete project source code, including its package configuration, assets, components, and styling files.

1. Clone the repository:

   ```bash
   git clone https://github.com/vasavi2508/perfect-snapshot1.git
   ```

2. Open the project folder:

   ```bash
   cd perfect-snapshot1
   ```

3. Install the project dependencies using the package manager configured in the complete project.

4. Start the development server using the project's configured development script.
